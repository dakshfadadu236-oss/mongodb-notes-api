# mongodb-notes-api
A REST API backend for managing notes using Node.js, Express.js, MongoDB Atlas, and Mongoose with full CRUD operations.

# Notes API Backend

A simple Notes REST API built using Node.js, Express.js, MongoDB Atlas, and Mongoose.

## Features
- Create Note
- Read Notes
- Update Note
- Delete Note

## Technologies
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
